# Souline v1.0.0

The first stable release of Souline (formerly AudioFerry): stream Windows system audio to HomePod and other AirPlay receivers.

## Highlights
- No more dropouts in long listening sessions: speaker latency now stays inside the 250 ms – 1.5 s range that HomePod accepts.
- Latency in milliseconds, with an opt-in experimental 0 ms mode.
- New Windows 11 style interface that follows your light/dark theme.
- One-click installer for the current user, no administrator rights needed.
- Your AudioFerry settings are carried over automatically.

## Downloads
- `Souline-Setup-v1.0.0.exe`: installer (recommended)
- `Souline-v1.0.0-win-x64.zip`: portable version
- `SHA256SUMS.txt`: checksums

The files are not code-signed, so Windows SmartScreen may show an unknown-publisher warning.
