# Souline v1.0.1

A small fix-up release for v1.0.0.

## Fixed
- Uninstalling no longer reports "some components could not be removed" after exiting from the tray.
- Faster start-up: Souline no longer unpacks itself to a temporary folder every time it opens.

## Changed
- The app appears simply as "Souline" in Windows Settings > Apps.
- If no speaker is found, Souline reminds you to allow it through Windows Firewall on private networks.

## Downloads
- `Souline-Setup-v1.0.1.exe`: installer (recommended). Installing over v1.0.0 keeps your settings.
- `Souline-v1.0.1-win-x64.zip`: portable version
- `SHA256SUMS.txt`: checksums

The files are not code-signed, so Windows SmartScreen may show an unknown-publisher warning.
